# 水下考古潜水记录（复测台）

直接打开`index.html`使用。点击平面图落点，填写潜次、深度、定位来源后保存复测记录。

## 复测流程

- 保存时记下潜次、定位来源及校准状态；新编号直接落档。
- 同一编号的新坐标先留在**待确认区**，确认后才替换原标记，旧值自动存入复测档案。
- 深度变化超过原值两成、或定位来源未校准的记录会被标出，原值与新值并列展示，确认前原标记继续有效。
- 潜次结束后在待确认区选择潜次并“结束潜次”，按编号逐条确认替换或驳回。
- 地图、类型筛选、潜次时间线（含复测替换记录）和导出JSON保持可用。

## 文件结构

- `index.html` — 页面结构与样式
- `js/coords.js` — 坐标换算：平面图百分比坐标 ↔ 经纬度、深度解析与变化计算
- `js/archive.js` — 复测档案：标记、待确认记录、替换历史的存储与业务规则
- `js/page.js` — 页面操作：地图、表单、列表、时间线与待确认区的渲染和交互
