# 水下考古潜水记录 · 复测台

直接打开`index.html`使用。

## 功能

- 点击沉船平面图添加标记，类型筛选、编辑、删除、潜次时间线和导出JSON继续可用。
- 保存记录时记下**潜次**和**定位来源**（含已校准/未校准状态）。
- 同一编号的新坐标/新深度先进入**待确认区**，不会直接覆盖；确认后才替换原标记，旧值完整留存在标记历史（列表显示“留存旧值×N”，导出文件含`history`）。
- 深度变化超过原值两成，或定位来源未校准的复测记录，待确认区并列列出**原值与新值**（含网格坐标、来源、位移），确认前原标记继续有效；地图上新坐标以黄色虚影标示。
- 潜次结束后点“潜次结束·处理待确认”，在待确认区按编号逐条确认或驳回，可按潜次筛选。驳回的记录丢弃，原标记不动。

## 业务文件

- `coords.js`：坐标换算（平面图百分比 ↔ 局部网格米制、深度解析与变化率、位移距离）
- `archive.js`：复测档案（标记/待确认记录/历史旧值的存储与确认、驳回规则）
- `app.js`：页面操作（地图、表单、筛选、时间线、待确认区、导出）
